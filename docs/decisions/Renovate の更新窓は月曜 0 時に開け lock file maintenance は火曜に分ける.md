# Renovate の更新窓は月曜 0 時に開け lock file maintenance は火曜に分ける

## 背景と課題

月曜 8:00 に weekly-renovate-review routine が Renovate の PR を横断で読み、10:00 に判断を始められるレポートを出す。routine が読む前に、自動マージを終えておきたい。

3:00 までは開発中で通知を受けたくないので、更新窓を月曜 3:00-7:59 にしていた。lock file maintenance も[同じ窓に揃えていた](https://github.com/nozomiishii/renovate/pull/909)。2026-10-12 は、routine が自動マージの途中を読んでいた。

```
03:00  窓が開く
05:26  最初の PR が作られる
08:09  routine 開始、09:43 終了
12:02  最後の自動マージ。重い repo は PR 作成から 5〜6.5 時間かかった
13:35  lock file maintenance 3 件が conflict のまま残る
```

重い repo で時間がかかるのは、マージが次の流れを 1 件ずつ繰り返すため。

```
1 件マージする
  ↓
残りの PR が pnpm-lock.yaml で conflict する
  ↓
次の Mend の job (最大 4 時間後) で rebase される
  ↓
CI が通ってマージされる
```

lock file maintenance は同じ窓の更新 PR すべてと conflict し、10/12 は最後まで残った。

## 検討した選択肢

### 更新窓の開始時刻

最初の job までの待ち (10/12 は 2.5 時間、最悪 4 時間) とマージ (6.5 時間) を足して、自動マージが終わる時刻を見積もった。

| 選択肢     | 評価                                                                                  |
| ---------- | ------------------------------------------------------------------------------------- |
| 日曜 21:00 | 10/12 並みなら 6:00、最悪 7:30 に終わり、8:00 に間に合う。開発中に割り込む時間が最も長い |
| 日曜 22:00 | 10/12 並みなら 7:00、最悪 8:30 に終わる                                               |
| 日曜 23:00 | 10/12 並みなら 8:00、最悪 9:30 に終わる                                               |
| 月曜 0:00  | 10/12 並みなら 9:00、最悪 10:30 に終わる。開発中に割り込む時間が最も短い              |

### lock file maintenance の時刻

| 選択肢             | 評価                                                                     |
| ------------------ | ------------------------------------------------------------------------ |
| 更新窓と同じ月曜   | 更新 PR すべてと conflict する                                           |
| 更新窓の前の日曜夜 | 更新 PR と conflict しない。メンテナンスの後に更新が入る順番になる       |
| 更新窓の翌日の火曜 | 月曜の更新が入った後の依存で lockfile を作り直せる。月曜の更新 PR とはほぼ重ならない |

## 決定

- 更新窓を月曜 0:00-4:59 にする。開発中への割り込みが最も短い案から始める
- lock file maintenance は火曜 0:00-4:59 にする

## 結果

### 良くなったこと

- 月曜のマージから lock file maintenance が外れ、conflict が減る

### 引き受けたコスト

- 月曜 0:00-3:00 の開発中に、更新 PR と自動マージが main に入る
- 月曜の時点では、間接依存が前週の lock file maintenance のまま残る
- 火曜の lock file maintenance は、月曜の weekly-renovate-review の対象から外れる

### 保留した論点

- 月曜 0:00 開始で 8:00 までに自動マージが終わるか。[2026-10-19 の結果を見て、窓をさらに早めるか決める](https://github.com/nozomiishii/renovate/issues/921)
